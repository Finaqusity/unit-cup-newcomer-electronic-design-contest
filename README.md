# 优利德杯新生电子设计竞赛 · B 题 周期信号测量分析装置

基于 STM32F103C8T6 的周期信号测量分析装置固件。装置仅使用**一个信号输入引脚**，可对直流信号与周期交流信号进行测量，通过板载按键切换模式并在 0.96 寸 OLED 上显示测量结果与输入波形。

本仓库为软件部分（Keil MDK 工程 + 全部源码与注释），并附竞赛题目原文与设计报告。

## 一、功能与实测指标

| 项目 | 赛题要求 | 实测结果 |
|---|---|---|
| 直流模式 | 0～5 V（拓展 −5～5 V），误差 < 10 mV | 未标定时 ±2～4 mV；按 12 点实测回算，现场标定后全量程最大约 7 mV |
| 交流模式 | 正弦：基础 1～10 kHz、Vpp 500 mV～2 V；拓展 100 Hz～20 kHz、Vpp 100 mV～5 V。Vpp 与频率误差 < 10% | Vpp 残差 1%～2.5%（其中主要来自信号发生器自身幅度精度），频率误差 < 1% |
| 模式切换 | 板载按键切换，反复切换仍正常，以切换后第一次数据为准 | 三态循环（直流 / 交流 / 波形），切换即触发一次即时测量 |
| 波形显示 | 任意波，−3.3～3.3 V，1～10 kHz，至少显示一个周期，无明显畸变 | 相干折叠重建单周期后按频率平铺显示，同时给出 Vpp 与频率 |
| 测量时间 | 每个波形测量 < 2 s | 直流约 0.08 s；交流/波形在最低采样率档约 0.2～0.6 s |

## 二、硬件平台

- 主控：STM32F103C8T6（72 MHz，无 FPU，20 KB RAM，64 KB Flash，12 位 ADC）
- 信号输入：**PA0（ADC1_IN0）**，唯一模拟输入引脚
- 显示：0.96 寸 SSD1306 OLED，软件 I²C
- 按键：KEY1 = PB4、KEY2 = PB3（原为 JTAG 引脚，固件启动时关闭 JTAG、保留 SWD 后复用为 GPIO，按下接地、内部上拉）
- 供电：±12 V（模拟前端）+ 3.3 V（MCU）
- 模拟前端：电阻分压衰减（衰减比约 0.266，0 V 输入对应 PA0 ≈ 1.72 V）→ 运放缓冲 → 钳位二极管 → ADC

### 关键设计

1. **标定：设备自测的分段线性查表**
   以设备自身的 ADC 读数标定 `Vadc → Vin`，共 116 个折点（输入每 0.1 V 一点），自动吸收 ADC 增益/失调/INL 与前端非线性；折点处误差接近 0，段间线性插值。范围外一律按首末段斜率**线性外推，不做钳位**。

2. **现场标定（CAL）：修正放在查表之前的 Vadc 域**
   更换信号发生器或线缆会带来偏置与分压比差异，且该差异物理上发生在 Vadc 域、会被前端局部斜率不均匀放大，因此在 Vadc 域做分段线性修正（而非在输出电压域做仿射）。锚点目标值就近吸附 0.5 V 栅格，含单调性守卫与同点去重。

3. **标定锚点掉电保持**
   锚点写入 Flash 最后一页（`0x0800FC00`，与代码区不重叠），带 magic / 版本 / 校验和；上电自动恢复，仅在标定内容发生变化时才擦写，减少擦写次数。

4. **交流 Vpp：整数周期窗内的 RMS × 2√2**
   用相位插值确定过零点，截取整数个周期后求方差（绕真均值），避免非整周期截断带来的泄漏；相比直接取最大/最小值，对噪声与采样相位不敏感。

5. **波形显示：相干折叠**
   多帧样本按分数相位累加到 128 个相位桶，等效于把噪声按 √(帧数 × 每帧周期数) 压低，同时完整保留任意波形的形状。折叠前对相位桶做可靠性判定（权重过低的桶由相邻可靠桶插值补全），并对"折叠中途信号被改变"的混帧结果作废，避免显示混合波形。

6. **采样率自动档位**
   三档采样率（20 / 200 / 400 kS/s）由 TIM3 周期整数分频得到，保证采样率精确；按测得频率自动选择并锁定档位，跨档时自愈。

## 四、构建与烧录

- 工具链：Keil MDK（ARMCC v5），工程文件 `led.uvprojx`
- **必须启用 C99**：Options for Target → C/C++ → Misc Controls 加 `--c99`（源码在 `for` 语句内声明变量）
- 输出：`Objects/led.axf`。当前固件占用：ROM 25.9 KB（Code 22306 + RO 4078 + RW 148）、RAM 10.6 KB（RW 148 + ZI 10716）/ 20 KB；代码止于约 `0x08006800`，与存放标定锚点的 Flash 末页 `0x0800FC00` 不重叠
- 烧录：SWD（调试器以 SWD 模式连接；固件启动即关闭 JTAG，不能用 JTAG 模式）

## 五、标定数据的复现与维护

- `Algorithm/Measure.c` 中的 `CAL_VADC_MV[]` / `CAL_VIN_MV[]` 为**设备实测原始数据**（2026-10-16 采集，输入 −6～+5.5 V、每 0.1 V 一点），请勿手工修改或平滑处理：其中的折点起伏是器件真实非线性，平滑会在折点附近引入系统性误差。
- 更换前端元件或重新焊接后，应先抽取若干点与原表比对：**偏差均匀（纯平移或微小增益变化）时由现场标定吸收，不必重扫**；只有局部斜率确实改变时才重新采集整表。
- 重新采集需临时启用 `FRONT_END_BYPASS`（使显示直接为 PA0 电压），**采集完成后必须改回 0**；现场标定必须在 `FRONT_END_BYPASS = 0` 下进行。
- 全片擦除会一并清除 Flash 末页的标定锚点，烧录时优先使用"按段擦除"。

## 七、已知限制

- 交流模式的 Vpp 按正弦有效值关系（×2√2）换算，非正弦信号请使用波形显示模式读取真实峰峰值。
- 高频且占空比极端的脉冲信号，其低电平持续时间可能不足数个采样点，过零检测与波形重建存在物理极限（受 ADC 最高采样率限制）。
- 信号源输出幅度精度会直接进入比对结果；本装置与信号发生器拨盘之间约 1%～2.5% 的残差已确认主要来自信号源。
